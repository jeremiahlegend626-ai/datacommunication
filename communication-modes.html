Communication Modes

Simplex, Half Duplex, Full Duplex

← Back to Home
  • Simplex: One-way communication where data flows in only one direction. The sender transmits and the receiver receives, but there is no return channel for feedback. Example: Television broadcasting and radio transmission.
  • Half Duplex: Two-way communication, but data can only flow in one direction at a time. One party transmits while the other receives, then they switch roles. Example: Walkie-talkies and CB radio require users to take turns transmitting.
  • Full Duplex: Two-way simultaneous communication where both parties can send and receive data at the same time without interruption. Example: Telephone conversations where both people can talk simultaneously.
