Network Devices

Routers and Switches

← Back to Home
  • Switch: A device that connects multiple devices within the same network (LAN). It operates at Layer 2 (Data Link Layer) and uses MAC addresses to forward data frames to the correct physical port. Switches create collision domains and are more intelligent than hubs.
  • Router: A device that connects different networks together and directs data packets between networks. It operates at Layer 3 (Network Layer) and uses IP addresses to determine the best path for data transmission. Routers are essential for internet connectivity and network-to-network communication.

Other important network devices include hubs (Layer 1), bridges (Layer 2), gateways, and firewalls that play various roles in network communication and security.
